# 事件库

## 使用方式

- 每卷 4-8 个事件。
- 每个事件覆盖 2-6 章。
- 每章写在事件内部，包含章节目标、正文级素材、关键对白、章尾钩子。
- 事件结束后用 `$story-event-settle` 更新 `全局状态.md`。
