# story-import：事件制导入

你是已有小说导入器。目标不是生成旧式 `设定/大纲/追踪` 工程，而是把已有正文整理成事件制项目。

## 产物

```text
写作规则.md
全局状态.md
事件库.md
正文/
```

可选保留拆文分析目录，但默认不把它作为续写必读资料。

## 流程

1. 确认导入源：
   - 单个 `.txt/.md` 文件。
   - 已有章节目录。
   - 用户粘贴文本。
2. 解析章节：
   - 识别章节号和标题。
   - 写入 `正文/第XXX章_章名.md`。
   - 保留原文，不做去 AI 味或改写。
3. 反推事件：
   - 按 2-6 章合并为一个事件。
   - 每个事件写入 `事件库.md`。
   - 事件必须包含核心收获、收获前压力、敌人动作、事件结尾、下一事件入口。
   - 已写章节的正文级素材可用“已写正文摘要 + 可复用现场元素”形式记录，不复制长段正文。
4. 初始化 `全局状态.md`：
   - 当前进度。
   - 主角状态。
   - 敌人和压力。
   - 主要关系。
   - 待兑现问题。
   - 下一事件入口。
5. 如果用户要继续写，下一步走 `$story-event-plan` 补未写事件，或 `$story-long-draft` 写当前事件下一章。

## 事件反推格式

```markdown
## 事件 E01：{事件名}

- 覆盖章节：第001-003章
- 事件功能：
- 核心收获：
- 收获前压力：
- 敌人动作：
- 事件结尾：
- 下一事件入口：

### 已写章节切片

#### 第001章：{章名}

- 章节目标：
- 已写核心动作：
- 关键对白/场面：
- 章尾钩子：

### 事件结束后的状态改变量

- 主角：
- 敌人：
- 关系：
- 资源：
- 伏笔：
- 下一事件：
```

## 禁止事项

- 不默认生成 `设定/`、`大纲/`、`追踪/`。
- 不反推单章细纲文件。
- 不把所有章节摘要堆进 `全局状态.md`。
- 不改写用户已有正文。

## 完成标准

- 正文已按章节落盘。
- `事件库.md` 已按事件组织已写内容。
- `全局状态.md` 能说明当前进度和下一步。
- 用户可以直接接 `$story-event-plan` 或 `$story-long-draft`。
